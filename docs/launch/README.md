# MHtoolkit Launch Operating Kit

This folder turns the first 500-user goal into a measurable operating plan.

## Start Here

1. Use `500-user-launch-plan.md` for targets, sequencing, and decision gates.
2. Use `campaign-links.csv` for every distributed link. Do not invent new UTM
   values without first adding them to the application allowlist.
3. Work `prospects.csv` from highest rank downward. Every row begins as
   `researched_not_contacted`; update it only after a real action.
4. Use `outreach-messages.md` and personalize the proof sentence. Do not imply
   endorsement, clinical efficacy, or App Store availability.
5. Review `weekly-scorecard.csv` every Monday using `npm run growth:report`.
6. Follow `release-checklist.md` before calling either mobile platform live.
7. Record every external action in `outreach-log.csv`. Gmail `Sent` proves a
   send, not delivery or engagement; only replies, referrals, partner shares,
   and attributed activations advance those respective metrics.

## Operating Rule

An activated user is a unique person who completes a first check-in. Visits,
installs, posts, emails, and replies are inputs, not users. The 500-user target
is complete only when the post-launch aggregate activation report reaches 500
with zero unattributed activations.

MHtoolkit is a self-help reflection tool, not therapy, diagnosis, treatment, or
emergency support. Partner and creator copy must preserve that boundary.
