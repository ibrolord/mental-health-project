# MHtoolkit brand assets

The canonical app mark is `mobile/assets/icon.svg`. The iOS app icon, splash
artwork, favicon, web icons, Apple touch icon, and social preview are generated
from tracked source artwork so the App Store and web product stay consistent.

Run `npm run brand:generate` from the repository root after changing the mark or
the botanical artwork. Commit both the source and generated assets.

Generated web assets:

- `public/icon.svg`
- `public/icon.png`
- `public/favicon.png`
- `public/apple-touch-icon.png`
- `public/og-image.png`
